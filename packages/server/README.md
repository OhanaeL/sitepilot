# @sitepilot/server

A fetch-standard chat-completions proxy for @sitepilot/core: keeps your LLM key server-side, pins the model, validates the body. Optionally puts TypeSafe's Jev in front of the LLM (`jevRouter`), so plain on-screen actions skip the LLM.

See the [repository README](https://github.com/OhanaeL/sitepilot#readme) for usage.
